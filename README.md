# Quant Trading Strategy

머신러닝 기반 한국/미국 주식 자동매매 전략

## 전략 성과

| 전략 | 연수익률 | Sharpe | MDD | 기간 |

## 전략 구조

### 한국 전략
- 유니버스: KOSPI 상위 100개 종목
- 팩터: 모멘텀, 가치, 퀄리티, 단기반전, 변동성
- 모델: XGBoost
- 리밸런싱: 월 1회

### 미국 전략
- 유니버스: S&P 500 주요 종목 160개
- 팩터: 주가 기반 6개 + 재무 시계열 3개 (SimFin)
- 모델: XGBoost (재무 팩터 포함)
- 리밸런싱: 월 1회

## 기술 스택

- Python, XGBoost, TensorFlow
- KIS API (한국투자증권 자동매매)
- SimFin (재무 데이터)
- yfinance, FinanceDataReader
